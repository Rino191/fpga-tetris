# FPGA Tetris

FPGA implementation of the classic Tetris game written in Verilog.

## Features

- VGA video output
- Seven tetromino types
- Piece rotation
- Collision detection
- Line clearing
- Game over screen
- Hardware controls

## Controls

| Button | Action |
|----------|----------|
| Left | Move left |
| Right | Move right |
| Rotate | Rotate piece |
| Drop | Fast drop |
| Reset | Restart game |

## Hardware

- Verilog HDL
- VGA Output
- FPGA Development Board

## Files

- `vga.v` - Main game implementation
- `ucf.ucf` - FPGA pin constraints
